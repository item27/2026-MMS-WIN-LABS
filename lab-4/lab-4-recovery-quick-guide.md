# Лабораторная 4: удаление и восстановление Failover

VM104 - основной DHCP 10.0.0.1, VM109 - резервный DHCP 10.0.0.2, VM105 - клиент. Все три ВМ должны быть включены

## 1. Показать и удалить связь

На VM104: Server Manager -> Tools -> DHCP -> IPv4 -> Scope [10.0.0.0] Lab2Scope -> Properties -> Failover

Показать Lab4, Hot standby, Active, резерв 35%, MCLT 30 минут, интервал 1 минута и Normal/Normal. На VM109 роль Standby

1. На VM104 нажать правой кнопкой по области -> Deconfigure Failover. Подтвердить удаление области с резервного сервера и дождаться успеха
2. IPv4 -> Properties -> Failover -> выделить пустую связь Lab4 -> Delete. Проверить пустой список Scopes и подтвердить
3. Исходную область на VM104 сохранить. На VM109 обновить IPv4 и проверить отсутствие области 10.0.0.0

## 2. Запустить восстановление

На VM104 открыть PowerShell от имени администратора. Скрипт и JSON уже находятся в C:\Lab4

```powershell
C:/Lab4/lab4-repair-failover.ps1 -ConfigPath C:/Lab4/repair-parameters.json -Apply
```

Ввести общий секрет из задания awin_4_2025.docx. Ожидается RESTORED. Заново открыть Properties -> Failover на обоих серверах: Normal/Normal, роли Active и Standby, прежние параметры. Область на VM109 должна появиться снова

Повторить команду: ожидается UNCHANGED без запроса секрета

## 3. Проверить клиента

На VM105 в командной строке администратора выполнить по одной, дождаться завершения каждой

```text
ipconfig /release
ipconfig /renew
ipconfig /all
```

Release освобождает аренду, renew запрашивает новую, all показывает параметры. Проверить DHCP Enabled: Yes, свежий Lease Obtained, адрес из области, DHCP Server, шлюз и DNS

В конце проверки 18 ноября 2026 года: IP 10.0.0.100, DHCP Server 10.0.0.1, шлюз 10.0.0.1, DNS 10.0.0.2

## Если renew завершился таймаутом

В нашем прогоне связь восстановилась, но выдача заработала после отдельного перезапуска DHCP на VM104

```powershell
Restart-Service DHCPServer
```

Дождаться завершения. Заново открыть Failover на обоих серверах и проверить Normal/Normal. На клиенте повторить release, renew и all. Один статус Normal успешную выдачу адреса не доказывает

Скрипт восстанавливает только отсутствующую связь при сохранённой исходной области. Сам службу не перезапускает. При конфликте настроек останавливается. Подробности проверки и диагностики - в lab-4-recovery-guide.md
