# Инструкции для агентов

- После каждого завершённого этапа создавай коммит и отправляй его во все настроенные удалённые репозитории (`git push`).
- Для любого добавляемого или изменяемого текста используй скилл `humanizer` и делай финальную проверку естественности формулировок. Не применяй этот скилл к исходному коду, командам, идентификаторам и значениям.
- Используй только короткое тире `–`. Символ длинного тире `—` не используй.
- Стрелки записывай только ASCII-последовательностью `->`. Не используй символ `→`.
