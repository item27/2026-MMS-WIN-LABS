# 2026-MMS-WIN-LABS

Материалы лабораторных работ по администрированию Windows Server.

## Структура

- `lab-1/` - лабораторная работа №1: задание, отчёт, теория для защиты, сценарии и скриншоты.
- `lab-2/` - лабораторная работа №2: Active Directory, DNS, DHCP, файловые права, групповые политики и автоматизация.

Для каждой работы используется каталог `lab-x/` и ветка `lab-x-attempt-y`.
