# Практическая работа №1

## Основные инструментальные средства управления Windows Server

## Цель

Получить практические навыки работы с инструментами управления Windows Server на примере локальных учётных записей и параметров сетевых интерфейсов.

## Исходные требования

В методических материалах указаны Oracle VirtualBox и Windows Server 2012, 2016 или 2019. Работа выполняется на Windows Server 2025 Standard Evaluation с Desktop Experience в Proxmox VE. Это не меняет задания: для выполнения используются те же MMC, CMD, PowerShell, локальные пользователи, группы и сетевые параметры.

В качестве идентификатора команды используется:

```text
GMAKMA
```

Имена объектов части 1:

```text
Пользователь: UPart1GMAKMA
Группа:      GPart1GMAKMA
```

## Краткая теория

Windows Server предоставляет несколько видов средств управления:

- графический интерфейс, элементы Панели управления и стандартные консоли;
- MMC, в которой можно собрать несколько оснасток, скриптов и внешних программ в один файл `.msc`;
- `cmd.exe`, консольные утилиты и сценарии `.bat` / `.cmd`;
- PowerShell и сценарии `.ps1`.

MMC создаётся утилитой `mmc.exe`. Её можно использовать для управления локальным или удалённым компьютером. CMD-сценарии работают с текстовыми командами, а PowerShell использует cmdlet-ы и объекты .NET.

## Часть 1. Консоль MMC

1. Запустить Windows Server и войти с правами Administrator.
2. Запустить `mmc.exe`.
3. Создать сборную консоль с оснастками локального компьютера:
   - Computer Management;
   - Services;
   - Event Viewer;
   - Shared Folders.
4. Добавить в консоль папку `Tools`.
5. Создать в `Tools` задачу, открывающую окно Network Connections. Используемая команда:

   ```text
   Command:    control.exe
   Parameters: ncpa.cpl
   ```

6. Через созданную консоль создать пользователя `UPart1GMAKMA` и группу `GPart1GMAKMA`.
7. Включить `UPart1GMAKMA` в `GPart1GMAKMA`.
8. Сохранить основную консоль в:

   ```text
   C:\Console\lab-1.msc
   ```

9. Войти в Windows под новым пользователем и запустить сохранённую консоль.
10. Попытаться перезапустить DNS Client через оснастку Services. Если DNS Client нельзя использовать из-за политик текущей версии Windows, проверить DHCP Client.
11. Запустить оснастку от имени Administrator через GUI или `runas` и повторить проверку управления службой.
12. Настроить IPv4 на выделенном изолированном интерфейсе `Lab-Isolated`:

   | Параметр | Значение |
   |---|---|
   | IP-адрес | `192.168.1.10` |
   | Маска | `255.255.255.0` |
   | Шлюз | `192.168.1.1` |
   | DNS | `8.8.8.8` |

Основной сетевой адаптер VM не изменять.

## Часть 2. Утилиты командной строки CMD

1. Войти в Windows с правами Administrator.
2. Создать `script21.cmd` с утилитой `net`. Сценарий должен:
   - запросить строку из четырёх символов без пробелов;
   - создать пользователя `UPart2STR`;
   - создать группу `GPart2STR`;
   - включить пользователя в группу;
   - активировать пользователя.

   Здесь `STR` означает введённую строку.

3. Создать `script22.cmd` с утилитой `netsh`. Сценарий должен запросить `Auto` или `Manual`:
   - `Auto` включает автоматическое получение IP-адреса, маски, шлюза и DNS через DHCP;
   - `Manual` устанавливает параметры IPv4 из части 1 только для `Lab-Isolated`.

4. Добавить `script21.cmd` и `script22.cmd` в папку `Tools` основной MMC-консоли.

## Часть 3. PowerShell

1. Войти в Windows с правами Administrator.
2. Создать `script31.ps1`. Сценарий должен:
   - запросить строку из четырёх символов без пробелов;
   - создать пользователя `UPart3STR`;
   - создать группу `GPart3STR`;
   - включить пользователя в группу;
   - активировать пользователя.

3. Создать `script32.ps1`. Сценарий должен запросить `Auto` или `Manual`:
   - `Auto` включает получение IP-адреса, маски, шлюза и DNS автоматически;
   - `Manual` устанавливает параметры IPv4 из части 1 только для `Lab-Isolated`.

4. Добавить `script31.ps1` и `script32.ps1` в папку `Tools` основной MMC-консоли.
5. Сохранить отдельную копию консоли, которую обычный пользователь не сможет изменять:

   ```text
   C:\Console\LAB-1-USER.msc
   ```

   Использовать режим:

   ```text
   User mode – limited access, single window
   Do not save changes to this console
   ```
