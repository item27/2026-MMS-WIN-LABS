# Лабораторная работа №1 — Инструменты управления Windows Server

## Идентификатор команды

`GMAKMA` — Кургут Михаил Александрович, Гунин Михаил Александрович.

## Задание

1. Создать MMC-консоль с оснастками: «Управление компьютером», «Управление службами», «Просмотр журнала событий», «Управление общими папками».
2. Добавить `Tools` и задачу открытия «Сетевых подключений».
3. Создать `UPart1GMAKMA` и `GPart1GMAKMA`, включить пользователя в группу.
4. Сохранить MMC в `C:\Console\`, проверить запуск и управление службой обычным пользователем и администратором.
5. Установить IPv4 `192.168.1.10/24`, шлюз `192.168.1.1`, DNS `8.8.8.8`.
6. Создать `script21.cmd`, `script22.cmd`, `script31.ps1`, `script32.ps1`; добавить их в `Tools`.
7. Сохранить неизменяемую обычным пользователем копию MMC-консоли.
