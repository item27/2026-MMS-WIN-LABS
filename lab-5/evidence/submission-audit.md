# Сверка лабораторной №5 с заданием

19 ноября 2026 года сверили исходный DOCX, Markdown, материалы выполнения и свежий вывод PowerShell на первом сервере. SHA-256 файла из Downloads совпадает с копией в репозитории. Для сверки формулировок используем [текст задания](../lab-5-task.md)

| Пункты ТЗ | Что подтверждено | Что осталось |
|---|---|---|
| Часть 1, п. 1-4 | Два сервера по 2 ядра, контроллер и член GMAKMA.local, снимки обеих ВМ, адреса 10.0.0.1/8 и 10.0.0.2/8, доменный канал и пинги в обе стороны | Уточнить допустимость выбранных UTM и Windows Server 2022, если преподаватель требует версии из ТЗ |
| Часть 2, п. 1-6 | Четыре диска по 4 ГиБ, NTFS в C:\Volume1, результаты физических и логических дисков, разделов и томов | Выполнено |
| Часть 2, п. 7-9 | d2-d4 уже Offline, d1 с Volume1 пока Online. Скрипт для T: прошёл проверку синтаксиса | Перевести d1 в Offline через Диспетчер дисков, проверить отмену и создание T:, записать результат проверки тома, очистить учебные тома и разделы |
| Часть 3, п. 1-9 | План и конвейер выбора d1-d3 по серийным номерам в гайде | Создать W:, проверить файлы при отключении d3, снять деградацию и восстановление через d4, вернуть d3, очистить диски и выполнить скрипт DiskPart для V: |
| Часть 4, п. 1-11 | Роли, команды и схема описаны в гайде | Развернуть LUN1 размером 5 ГиБ на V:, подключить R: с ad-srv-2, повторить инвентаризацию и проверить сеанс, фильтр iSCSI и запись на R: |
| Часть 5, п. 1-5 | Команды зеркала, удаления и двойной чётности подготовлены | Добавить 7 дисков по 10 ГиБ, создать пул через Server Manager, измерить максимум зеркала, удалить его и измерить максимум двойной чётности |

Адреса и DNS проверены на собственном стенде. ВМ созданы для ЛР5, поэтому останавливать DHCP с готовых машин ЛР4 не потребовалось. В исходном ТЗ указаны VirtualBox и Windows Server 2012/2016. Фактическая среда по договорённости с пользователем - UTM и Windows Server 2022 x64

В гайде есть все 13 вопросов с формулировками из DOCX. В отчёт перенесены 11 ответов, включая сопоставление четырёх уровней хранения и измерения Volume1. Вопрос №5 пока содержит расчёт около 8 и 12 ГиБ, после создания массивов нужны фактические значения. Для вопросов №9 и №13 требуются результаты частей 4 и 5

| Артефакт из ТЗ | Состояние |
|---|---|
| Конвейер только для d1-d3 | Есть в гайде, результат на созданном W: предстоит проверить |
| Скрипт для T: | Есть в scripts, парсер Windows ошибок не нашёл. Нужен запуск с проверкой отмены и согласия |
| Два скриншота RAID5 | Нужны кадры деградации и восстановления |
| Команда фильтра iSCSI | Есть в гайде, нужен вывод с ad-srv-2 |
| Команды Storage Spaces | Есть в гайде, нужны выполненные команды и замеры |

По структуре отчёт продолжает ЛР2 и ЛР3: общий шаблон титула, номера и подписи рисунков, краткие шаги с командами и результатом, отдельный раздел с оригинальными вопросами. Названия частей 1 и 2 дословно совпадают с ТЗ, пункты 2.1-2.6 теперь также названы дословно. Части 3-5 уже имеют точные заголовки в гайде. В отчёте эти части появятся вместе с результатами

До сдачи стоит сгруппировать 13 подпунктов подготовки по требованиям части 1 и оставить промежуточные экраны установки в гайде, если они не объясняют результат. В разделе защиты и в PDF нужно проверить читаемость длинных заголовков и команд. В текущей ветке ЛР5 доступен отчёт ЛР2, отчёт ЛР3 сверили в его отдельной ветке.
