# Сверка лабораторной №5 с заданием

Исходный DOCX совпадает с копией задания в репозитории. Все пять частей отражены в отчёте, выполненные действия проверены на двух ВМ

| Часть | Подтверждение |
|---|---|
| 1. Подготовительная | Две ВМ по два ядра, GMAKMA.local, сеть 10.0.0.0/8, проверка домена и связи в обе стороны, исходные снимки |
| 2. Разделы | Четыре диска по 4 ГиБ, NTFS в Volume1, четыре уровня инвентаризации, Offline, отказ и подтверждение в скрипте T:, NoErrorsFound и очистка учебных дисков |
| 3. RAID | W: на d1-d3, два файла и SHA-256, отключение d3 и Failed Redundancy, восстановление на d4 и Healthy. d3 возвращён, четыре диска очищены, V: создан скриптом DiskPart |
| 4. iSCSI | LUN1 на V:, разрешение инициатора по IP, R: на второй ВМ, проверка записи и чтения, четыре уровня инвентаризации и отдельный фильтр iSCSI. Повторная проверка после перезапуска s1 |
| 5. Storage Spaces | Семь дисков по 10 ГиБ, Lab5Pool создан через Server Manager. Mirror 30 ГиБ измерен и удалён. Parity 36 ГиБ, Fixed, PhysicalDiskRedundancy=2 |

Обязательные материалы находятся в самом отчёте: конвейер отбора d1-d3, полный сценарий создания T:, оба состояния RAID5, команда фильтра iSCSI и команды двух схем Storage Spaces. Добавлен полный скрипт DiskPart для V:. Есть все 13 ответов с формулировками вопросов из задания

Для стенда выбраны UTM и Windows Server 2022 x64. В ТЗ названы VirtualBox и Server 2012/2016. Использованы две отдельные ВМ, DHCP с готовых машин ЛР4 останавливать не требовалось
